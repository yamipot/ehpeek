A userscript that turns E-H / ExH pages into a touch-optimized gallery reader. Inspired by [EhViewer-NekoInverter/EhViewer](https://github.com/EhViewer-NekoInverter/EhViewer).

## Features

- Touch-optimized layouts and controls for one-handed use
- Reader with paged and continuous-scroll modes
- Scroll preview for browsing galleries at a glance
- Gesture navigation, reading history, pinch zoom, two-column view, etc.

Each feature above can be enabled independently in settings.

EhPeek can work with the following scripts for a better experience and maintains best-effort compatibility with them; compatibility with other scripts is not guaranteed:

- [EhSyringe](https://github.com/EhTagTranslation/EhSyringe) (tag autocomplete, translation)
- [LOLICON Enhancer](https://sleazyfork.org/en/scripts/516145-lolicon-e-hentai-exhentai-enhancer) (tag autocomplete, quick tags/favorites, infinite scroll)

## Install

- Install [Violentmonkey](https://violentmonkey.github.io/) or another userscript manager. On Android, use a browser with userscript or extension support, such as [Via](https://viayoo.com/) or [Quetta](https://www.quetta.net/products/android).
- Install from one of these channels:
